# SDD-08｜编辑式排版系统与侧边栏作品集改版审查

**提出背景：**用户明确评价先前侧边栏版式“文字排版网页布局特别差”，要求参考优秀作品集，而不是继续按感觉调 CSS。  
**目标：**保留已验证的菜单交互和四张原始 Power BI 看板，通过重新梳理视觉层级提高可读性和内容识别效率。

## 1. 参考设计逻辑

- 数据分析作品：让一个真实分析成果成为内容主视觉，而不是让布局装饰替代数据证据。
- 侧栏式作品集：菜单承担导航职责，概览页不重复绘制“四个主题入口”卡片。
- 成熟产品界面：固定导航、统一的左对齐与间距、相对克制的辅助标签。
- 编辑式案例排版：用标题、正文、图像与有限的分隔线建立层级，不使用等权重卡片墙。
- 沿用 `personal_website` 的低饱和灰底与珊瑚强调，而非复制全屏视频与复杂动效。

## 2. 信息架构（保持六个侧栏入口）

| 页面 | 主视觉与内容 | 被删除的低价值重复 |
| --- | --- | --- |
| 项目概览 | 1 个项目标题 + 1 句项目定位 + 横向 3 指标 + 1 张原始 Power BI 看板预览 + 简短方法说明 | 四张重复的“选择分析主题”卡片、过量英文编号 |
| 经营 / 收入 / 用户 / 履约 | 业务标题 + 1 行核心看点 + 几乎全宽的原始截图 + 原图、PBIX、PDF | 仿浏览器三圆点窗口、重复长段文案 |
| 技术与证据 | 2 栏：问题与方法 / 对应 SQL 与结果来源 | 三列密集技术卡、过小的描述文字 |

**不修改**原始 PNG、PBIX、PDF、业务指标与历史 SQL 状态。

## 3. 字体、列宽和节奏

- 左侧固定侧栏：236px，导航正文 14px，项目名 20px。
- 右侧主标题：约 34–44px；模块标题：20–21px。
- 主体说明：15–16px、1.65–1.75 行高；脚注：12px。
- 数据数字：30–42px；单位使用比例字号而不是新的一整套卡片。
- 工作区外边距：24–50px 随屏幕宽度缩放；摘要三栏用同一基线。
- 正文行宽：约 740px 内；看板截图占主体宽度并保留正确 1551:874 宽高比。
- 不再用 9–11px 承担普通阅读正文，仅在辅助说明、编号与状态栏使用更小字号。

## 4. 交互不回退

- `#overview` / `#operations` / `#revenue` / `#customers` / `#fulfillment` / `#evidence` 六个 hash 路由保持。
- 桌面浏览器 `body` 保持 `overflow:hidden`，右侧内容独立滚动，保留固定菜单。
- 手机抽屉、遮罩、Escape 关闭、URL 前进/后退、图片放大、方向键切换维持。
- 首页预览直接点击进入真正的“经营总览”内容页，而不滚动到页面下方。
- 保持无框架、纯静态 GitHub Pages，资源相对路径不变。
