# SDD-07｜固定左侧导航工作台（取代下滑式单页）

日期：2026-11-02  
触发：用户明确要求 **“不要做下滑式的网页，做左边侧边菜单栏的那种”**。

## 需求决策
- 不再将“项目背景 → 关键成果 → 分析路径 → 看板”沿一条长网页纵向堆叠。
- 改成 `左侧固定菜单 / 右侧按菜单展示独立内容` 的数据分析工作台风格。
- 左侧 6 个入口：项目概览、经营总览、收入分析、用户行为、履约体验、技术证据。
- “项目概览”保留已完成的三项成果与四个业务主题快捷入口；四页 Power BI 使用同一个内容视图，根据路由切换真实 PNG。
- “技术证据”单独集中 SQL 入口与结果边界，避免首页长篇解释。
- 不加 Hero、视频、重动画、模拟 Power BI 筛选、重复 KPI 大屏。

## 交互规范
1. 主页 `#overview`，四页分别 `#operations`、`#revenue`、`#customers`、`#fulfillment`，证据 `#evidence`。
2. 菜单点击仅切换右侧；URL 哈希支持分享深链和浏览器后退/前进。
3. 桌面整体视口固定，**浏览器整页不滚动**；内容过高时只允许右侧 `.workspace` 内部滚动；左侧菜单不位移。
4. 移动端导航是可展开的抽屉，遮罩可点击关闭；Esc 可关闭，切换后抽屉自动收起。
5. 四个报表导航保持数据原图；支持放大、左右切换、Esc 关闭和 PBIX/PDF 下载。
6. 使用原个人网站的纸张色 `#efeeea` / 文字 `#252522` / 珊瑚 `#d56d63`，但去除首页视频及复杂光标。

## 证据真实性审查
- 商品收入四维核对 R$13,494,400.74 源于已有 Notebook 运行输出，并不是这次设计改造的新分析。
- 用户 94,983、历史复购 2,887 / 3.04%、评分 4.29 vs 1.70 来自已完成看板。
- 原 SQL 早已运行过；修订 SQL 的重新运行与原截图的严格同口径对账仍是单独任务。
- 页面只提供静态 Power BI 截图和可下载原文件；不称在线 Power BI 交互。

## 开发审查
- 范围：`index.html`、`styles.css`、`gallery.js`、README、浏览器冒烟测试、CI。
- 不改动 `assets/*.png`、`downloads/*.pbix`、`downloads/*.pdf`。
- Browser smoke test：宽 1440 与 375；6 路导航、3 个成果、body overflow hidden、报表图片切换、放大、键盘、手机抽屉、技术证据、无 JS error、无横向溢出。
- 通过 PR 触发 `.github/workflows/site-smoke.yml`，测试跑绿再合入 `main`。

## UI 取舍与风险
- 优点：看板独立占据右侧主区域，不再需要先阅读长网页；招聘官可一键切到感兴趣的内容。
- 代价：每页内容独立组织，不能通过普通整页滚动串联阅读；采用明确左栏栏目与概览快捷跳转解决。
- 小屏仍允许右侧内部滚动，以保证可访问性，**不是**完全禁止任何滚动。
- 在非常小的移动屏幕上 Power BI 原图文字会较小，保留点击放大/横向平移，不重绘图片内部控件。
