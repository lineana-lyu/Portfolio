- `eda.ipynb`：原 MySQL 查询和 Python 数据处理的已保存执行输出；单元 16 保存了月度、品类、RFM、州级商品收入求和。

- `docs/NOTEBOOK_EXECUTION_EVIDENCE.md`：之前已经核对过的执行结果。

## 正面成果
- 采用与 `personal_website` 相同的浅灰纸张/珊瑚强调视觉语言。
- 非全屏 Hero；不新增空洞装饰卡或额外图表，只有真实事实。
- 保留四张原始大屏、原图放大、键盘切换与 PBIX/PDF 下载。
- 关键发现区明确来源；每页导览同时说明相关性与观察窗口限制。

## 风险与后续
1. 原始 Notebook 保存了本地数据库连接设置：**不得不经脱敏直接上传**。证据页提供执行输出摘要，而非假装公开可重跑。
2. 复购和评分数字来自既有 Power BI 看板；新修订 SQL 尚未再次执行，不能写成已经由修订版复现。
3. 数据为 Olist 历史公开数据，不能以此声称某企业真实运营成果或经真实 AB 实验验证。
4. 待线下浏览器验收：1440px、375px、四标签切换、放大、证据入口及 PBIX 下载。
