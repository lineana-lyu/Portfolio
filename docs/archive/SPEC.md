# SPEC v2.1｜Olist 三段式静态看板作品集

**状态：已冻结（根据用户最新要求变更）**  
**更新时间：2026-11-02**

## 产品目标
让求职面试官快速知道这个项目为什么做、按什么业务顺序分析，并查看**四页真实 Power BI 大屏截图**。提供原始 `.pbix` 文件下载，不再要求注册 Microsoft Power BI Service 或公网 iframe 嵌入。

## 页面范围（仅三段）
1. **项目背景**：Olist 历史公开数据、MySQL 九表、多维经营分析、Power BI。
2. **分析路径**：经营总览 → 收入结构 → 并列的用户行为与履约体验。每个主题最多一个问题和一行分析指标。不是因果证明链。
3. **Power BI 看板展示**：同一位置切换四张真实 PNG；支持打开高清原图；提供 `downloads/Olist_电商经营分析.pbix` 下载和 PDF 辅助链接。

## 不做
- 不开发 ECharts、假装图片可筛选、未发布的 Power BI iframe 或额外商业策略模块。
- 不把网站变成分析报告；SQL 与详细指标留待独立仓库内容。
- 不声称已提供原生 Power BI 在线交互；交互仅限图片页面切换，报表交互需要 Power BI Desktop。
- 不把历史复购当成流失率，或将配送与评分关系写成因果证明。

## 验收（必须真实检验）
- AT-01 页面只有背景、分析路径、图片展示三段，无重复 KPI/策略卡。
- AT-02 图片内容来自已提供的四张 Power BI 截图，与上传 PDF 四页一致。
- AT-03 四个按钮切换正确图片；可查看原图；键盘可用。
- AT-04 下载链接返回真实约 31MB .pbix 文件，文件能被 Power BI Desktop 打开。
- AT-05 1440 和 375px 视口不出现横向溢出。
- AT-06 所有资源真实在部署托管上可访问（不能仅源码存在）。
- AT-07 通过 GitHub main 保存版本及复盘，发布前匿名访问验收。

## 发布阻断事项
四张图片和 PBIX 均为二进制，本轮连接器无法自动上传，因此 GitHub 仓库代码**不等于已经完成网站部署**。在用户从完整 ZIP 将 `assets/` 与 `downloads/` 推送至 GitHub 前，AT-06 与部署验收不可标为通过。

## 审查规则
每次修改先质疑：是否帮助快速了解项目？是否重复了 Power BI 已展示的信息？是否存在虚假的功能承诺？只保留能直接回答业务问题和展示实际成果的内容。
