**Do not use these files as the current website specification.** Some older links are relative to their former locations and may not resolve after archival. The current scope is described in the root [README](../../README.md) and [QUALITY review](../QUALITY.md).

- `SPEC.md`, `REVIEW.md`: legacy specs and critiques
- `changes/`: CR-001/CR-002 scope changes
- `reviews/`: SDD-01 through SDD-05 review records

The present site is static and has just three visible modules: background, analysis topics and the existing Power BI screenshot gallery.
